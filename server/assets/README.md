# Conteudo de audio

Os pacotes de Release incluem as vozes Piper e as musicas de fundo usadas pela live. O instalador baixa e verifica esses pacotes compartilhados para Windows e Linux.

Os arquivos de audio nao ficam no repositorio de codigo para evitar um clone de varios gigabytes. Eles sao publicados como anexos da mesma Release e instalados automaticamente em `server/assets`.
